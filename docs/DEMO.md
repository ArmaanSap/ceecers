# 90-second demo path

Rehearse this once. Every step uses features that are tested.

1. **0:00 · Arrival.** Let the orbital-to-surface arrival play (skip nothing). Say: "Real NASA Mastcam-Z panoramas and the real Perseverance traverse, placed on the Jezero crater floor."
2. **0:10 · Plan.** Left panel: pick **Delta Edge**. Point out the tasks only exist in this region (the sample handoff appears only here). Add *Delta layer record* and *Receive Perseverance sample*. Press ★ Priority on one stop. **Build mission.**
3. **0:25 · Plan panel.** Right side fills in: stops, ETAs, reserve gauge, and "DEM check: steepest 12°". Tick *Steep ground (DEM)* in the ☷ menu to show the slope overlay.
4. **0:35 · Walk.** Press **Start** (use 50x). The walk pauses at the first stop; read the printout aloud: "what to look for" changes every run. Click **Continue**.
5. **0:55 · CAPCOM + alert.** Ask CAPCOM "Why this route?". Open ⚙ Options → Safety drills → Dust-storm warning (labelled simulated). Show that only two alerts stack and they fade.
6. **1:10 · Abort.** Press **Abort → Base**; the astronaut returns along the recorded track.
7. **1:20 · Debrief.** Summary dialog + CAPCOM debrief; Export log JSON.
8. **1:30 · Close.** "Every number is labelled historical, modeled, simulated or derived. The slope grid is real 20 m CTX data; the radiation figure is a modeled estimate."

VR panoramas are an optional extra: open any stop's panorama and press Enter VR if a headset is connected.
